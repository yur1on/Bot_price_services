# Newbot on Django

Проект переведен на Django так, чтобы каталог устройств и цен редактировался через админку.

## Что теперь хранится в Django

- устройства и цены на переклейку;
- варианты дисплеев: оригинал и копия;
- пользователи Telegram;
- блокировки;
- история запросов.
- текст кнопки `Инфо`.

## Первый запуск

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Применить миграции:

```bash
python manage.py migrate
```

3. Импортировать текущий каталог из `baza_*.py`:

```bash
python manage.py import_legacy_catalog
```

4. При необходимости перенести старых пользователей и запросы:

```bash
python manage.py import_legacy_users --source user_queries.db
```

5. Создать администратора:

```bash
python manage.py createsuperuser
```

6. Запустить админку:

```bash
python manage.py runserver
```

Админка будет доступна по адресу [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/).

## Где что редактировать в админке

- `Каталог устройств -> Устройства` — добавление новых моделей и цен.
- `Каталог устройств -> Пользователи Telegram` — пользователи, которые нажали `/start`, и их блокировка.
- `Каталог устройств -> Тексты бота` — текст для кнопки `Инфо`.

## Запуск бота

После миграций и импорта бот запускается как раньше:

```bash
python app.py
```

Теперь бот читает каталог устройств из Django БД, а не из словарей.
Пользователь начинает работать сразу после `/start`, без регистрации.
До нажатия `/start` бот не показывает модели и просит сначала авторизоваться.

## Docker

Через `docker-compose` поднимаются два сервиса:

- `bot` для Telegram-бота;
- `web` для Django-админки на порту `8000`.
